# NeuroDiary

**NeuroDiary** is an AI-powered digital diary designed to help users capture their daily thoughts, track their moods, and gain meaningful insights through AI-driven sentiment analysis. It combines journaling with intelligent features to promote self-reflection and mental well-being.

---

## ✨ Features

- 🤖 AI-powered journal analysis using Groq AI
- 😊 Mood tracking and sentiment analysis
- 📝 Create, edit, and manage diary entries
- 🔍 Search and organize journal history
- 🔐 Secure JWT-based authentication
- 💳 Stripe payment integration
- 📱 Responsive and user-friendly interface

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- RESTful APIs
- JWT Authentication

### Database
- MongoDB

### AI & Integrations
- Groq AI
- NLP (Natural Language Processing)
- Stripe API
